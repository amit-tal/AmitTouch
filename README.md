# AMIT TOUCH — Nail Studio Booking

אפליקציית זימון התורים של AMIT TOUCH.

## מה קיים כרגע

• כניסת לקוחה באמצעות שם מלא ומספר נייד
• כניסת מנהלת ייעודית
• לק ג׳ל — 150 ₪ — 60 דקות
• מילוי — 200 ₪ — 90 דקות
• בנייה חדשה — 250 ₪ — 120 דקות
• הסרה בלבד — 25 ₪
• תוספות Nail Art ותיקוני ציפורן
• הסרה בלבד מדלגת על שלב התוספות
• Buffer אוטומטי של 30 דקות אחרי כל תור
• ממשק Liquid Glass בגווני תורכיז בהירים
• חלון ביטול תור עם מעבר ל־WhatsApp
• הכנה לסנכרון זמינות, יצירה ומחיקה מול Google Calendar

## הרצה

הפרויקט כרגע הוא Static Web App. ניתן לפרוס ישירות באמצעות GitHub Pages, Netlify או Vercel.

קובץ הכניסה הוא `index.html`.

## Google Calendar

כדי שסנכרון Google Calendar יעבוד עבור לקוחות אמיתיים, יש לחבר Backend מאובטח שמבצע את קריאות Calendar בשם בעלת הסטודיו. אין לחשוף OAuth token או Google credentials בקוד הדפדפן.

## Production

לפני פרסום מלא מומלץ להעביר את אימות המנהלת ואת פעולות Google Calendar ל־Backend ולהגדיר את מספר WhatsApp בצד השרת או בהגדרת סביבה.
